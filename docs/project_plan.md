# 개요
이 프로젝트에서는 구명조끼에 소형 저전력 장치를 달아서 무선으로 vpass 장치에 신호를보내고 조업자 익수 시 무선 신호가 끊기는 원리를 이용하여 익수감지를 수행, 무선 신호로 kill switch를 동작시켜서 배를 멈추는 솔루션을 개발할거야.

이때 한국은 어업 작업시 구명조끼 착용이 필수라 vpass 선원 출석 시 착용여부를 감지하고, 구명조끼에 홀센서 등을 이용하여 착용여부를 항상 추적하는 기능도 넣으려고 해.

또한 한국은 어업 작업 나갈 때 앱 등을 이용하여 출항/입항 신고등을 해야하는데 이를 vpass 상에서 수행할 수 있도록 할거야.

# 프로젝트 구조
## docs
- AI 프롬프트 등 필요한 문서들을 작성하는 공간이고 git ignore에 등록되었으면 좋겠어

## 펌웨어
- 구명조끼에 장착되는 장치의 펌웨어를 작성하는 공간이야.

## vpass-application
- vpass의 UI 등을 포함한 프로그램을 작성하는 공간이야. 기본적으론 윈도우에서 개발하고 검증하고 실제로는 라즈베리파이에서 동작하게 돼. 이 부분을 항상 염두해서 프로그램을 작성했으면 좋겠어.

## design
- pencil dev를 이용해서 디자인 시안을 관리할거야. 하나의 파일에서 여려 페이지를 작성하고 관리할 수 있으면 좋겠어.

# 기타
- kill switch나 하드웨어 등 폴더가 추가되긴 할건데 이건 나중에 추가할거야.

# 기술 스택
## 공통
- 여기 프로젝트는 git으로 관리, 모노 리포로 관리

## vpass apllication
- 기본적으론 python으로 구현
- UI 부분은 React, typescript으로 구현
- python 프로젝트는 uv로 관리

## firmware
- 나중에 변경될 수 있긴한데 기본적으론 ESP8266으로 개발, platformio 사용
