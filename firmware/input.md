여기에 esp8266을 이용해서 다음과 같은 기능을 수행하는 펌웨어 코드를 작성해줘. vscode와 platformio을 이용해서 개발할거야.

# 기능
1. 외장 스위치 입력이 있으면 착용 여부를 토글 시킴
2. 착용 상태로 설정되면 ping을 3초에 한 번씩 서버에 보냄
3. MPU9250 이용해서 사람이 크게 넘어짐을 감지하면 (운동량 변화 값이 크면) 서버에 넘어짐을 알림 (HTTP api로)

그리고 추가로 server폴더에 아래 내용을 수행하는 서버를 만들어줘.
1. ESP 보드에서 착용 여부를 수신 받아서 웹페이지에 시각화
2. 착용 상태에서 ping message 이력을 시각화
3. 넘어짐 감지하면 해당 내용 시각화
4. 넘어짐 감지 후 ping message가 10초간 (3번) 안 오면 웹페이지에 알림창 출력

# 수정
1. 가속도 센서로 넘어짐을 인지하고 5초 이내에 ping이 끊긴다면
2. 끊긴 상태가 10초 간 유지되면 웹페이지에 알림창 출력되도록 바꿈.
3. 끊긴 상태가 10초 이하라면 문제없이 계속 경과시간 지속
4. 가속도 센서가 넘어짐을 인지하고 5초 이내에 ping이 안 끊긴다면 문제없이 계속 경과시간 지속
